# JS EMAIL LIST

JavaScript exercise using a course-provided API to fetch random email addresses with Axios or Fetch.

# Target

The application retrieves 10 email addresses from the course-provided API and renders them dynamically inside a list element on the page.

**Bonus**

- Enhance the interface using CSS or Bootstrap.

- Add a button that, when clicked, fetches 10 new email addresses and replaces the previous ones.

# How to run

Clone or download the project, then open index.html in your browser.
